# Local Report Formatter

Only format Markdown files explicitly selected by the user and save the formatted copy locally.
Do not read unrelated personal data or transmit report content externally.
Explicit user confirmation is required before any action outside local formatting. If any external service is unavailable, fall back to local-only formatting.
